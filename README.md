# CineVerse

## Autor

Guilherme — Matrícula 22552371

## Descrição

O CineVerse é uma aplicação web que permite pesquisar séries, visualizar informações sobre elas e consultar episódios organizados por temporada. A aplicação é útil para pessoas que desejam descobrir novas séries e encontrar informações sobre seus episódios.

## API utilizada

- TVmaze API — https://www.tvmaze.com/api
- Endpoint de pesquisa: https://api.tvmaze.com/search/shows?q=termo
- Endpoint de séries: https://api.tvmaze.com/shows?page=1
- Endpoint de episódios: https://api.tvmaze.com/shows/{id}/episodes

## Funcionalidades

- Pesquisar séries pelo nome.
- Exibir sugestões de séries.
- Mostrar imagem, título, nota e gêneros.
- Visualizar detalhes das séries.
- Consultar episódios por temporada.
- Exibir número, nome, data e duração dos episódios.
- Permitir cadastro e login demonstrativos.
- Apresentar layout responsivo para computador e celular.
